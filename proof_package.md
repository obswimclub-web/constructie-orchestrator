The CMO engine now strictly returns `REQUIRED`, `N_A`, or `UNRESOLVED`. The `DONE` applicability state has been removed. The residual scope computation in the Completion Engine now specifically checks if a `REQUIRED` CMO is missing evidence, preserving the separation between applicability and fulfillment.

The final gate (`scripts/v1-gate.ts`) runs and actively consumes the `uc-evidence.json` generated by the tests. It statically asserts that the required conditions are met in the machine-readable output.

The Notion Execution State Ledger is kept at `IN_PROGRESS`. No premature PASS has been manufactured. It will be synchronized to the reviewed state only after re-review.
